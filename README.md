# Anitya Anand - Developer Portfolio

A premium personal portfolio showcasing my work as a Java Full Stack Developer, including full-stack systems, AI-powered applications and real-time engineering projects.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- JavaScript

## Features

- Responsive dark engineering-focused design
- Featured project showcase
- Developer activity and technology ecosystem sections
- Verified achievements and career information
- Resume access and direct contact links
- Smooth scroll and reveal animations
- Mobile-first responsive layouts

## Projects

- **CareerMetric AI** - AI-powered career intelligence platform.
- **ORIVEX** - AI-powered freelance marketplace.
- **TRAFIKKING X** - Real-time emergency response system.
- **PulseDrop** - Microservices-based real-time delivery platform.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

This Vite portfolio can be deployed to Vercel with:

- Framework: Vite
- Install command: `npm install`
- Build command: `npm run build`
- Output directory: `dist`

The portfolio uses anchor navigation and does not require SPA rewrite configuration. Add the real resume PDF at `public/resume.pdf` before deployment to enable the existing resume links.
